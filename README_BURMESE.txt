AKAR MOE SLOT ANALYZER - Android Project

ဒီဖိုင်သည် Android Studio ဖြင့် APK ထုတ်နိုင်သော project ဖြစ်သည်။ ဒီနေရာမှ တိုက်ရိုက် install လုပ်နိုင်သော APK ကို မထုတ်ပေးနိုင်သေးပါ။

APK ထုတ်ရန်
1. ZIP ကို ဖြည်ပါ။
2. Android Studio ကိုဖွင့်ပြီး Open ကိုနှိပ်ပါ။
3. AKAR_MOE_SLOT_ANALYZER folder ကိုရွေးပါ။
4. Gradle Sync ပြီးသည်အထိစောင့်ပါ။
5. Build > Build Bundle(s) / APK(s) > Build APK(s) ကိုနှိပ်ပါ။
6. app/build/outputs/apk/debug/app-debug.apk ထဲတွင် APK ရပါမည်။

မှတ်ချက်
- App သည် offline အသုံးပြုနိုင်သည်။
- Session မှတ်တမ်းကို ဖုန်းအတွင်း local storage တွင် သိမ်းသည်။
- ထည့်သွင်းထားသော wager/payout မှ Observed Return ကိုတွက်ပေးခြင်းသာဖြစ်သည်။
- Slot ၏ RNG ကို hack လုပ်ခြင်း၊ အနိုင်ရမည့်အချိန်ခန့်မှန်းခြင်း မလုပ်နိုင်ပါ။
- Observed Return သည် ဂိမ်းထုတ်လုပ်သူ၏ တရားဝင် RTP မဟုတ်ပါ။
